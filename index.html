Agente con tool use

Le da a Claude tres herramientas propias para configurar recordatorios a partir de lenguaje natural — "recuérdame mi cita el jueves que viene" — resolviendo lo que el modelo no puede hacer solo: saber la hora exacta, calcular fechas relativas, y guardar el resultado en disco.

Cada herramienta valida sus propios argumentos y devuelve errores descriptivos, para que el modelo pueda leer el error y reintentar en vez de romperse en silencio.

Cliente y servidor MCP

Un chatbot de documentos que implementa ambos lados del Model Context Protocol con el SDK oficial: servidor con herramientas, recursos y prompts predefinidos, y un cliente que los conecta a un LLM (NVIDIA Nemotron) por stdio.

Probado con éxito: el modelo pide la lista de documentos antes de leer uno cuando no sabe qué existe, y relee un documento antes de editarlo — sin que nada se lo indique explícitamente.

public

Pipeline RAG completo

Retrieval-Augmented Generation de punta a punta con embeddings 100% locales y gratuitos: tres estrategias de chunking, búsqueda semántica y BM25 combinadas por Reciprocal Rank Fusion, y respuestas con citas verificables al texto fuente exacto.

Para entender cómo funciona un RAG real — no solo mandarle el documento entero al modelo — sino segmentarlo bien, indexarlo por dos métodos distintos, y poder señalar de dónde salió cada respuesta.
